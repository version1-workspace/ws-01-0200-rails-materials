# よくある質問

## pending は成功ですか？

未実装の設問は `NotImplementedError` により pending になります。これは設問を残した状態を示すもので、完了ではありません。実装したら pending がなくなることを確認してください。

## テストが失敗したらどうしますか？

期待値、引数、返り値の型を読み直します。`puts` は表示するだけで返り値は期待と異なることがあります。返す設問では明示的な戻り値を確認してください。

## `nil` と `false` の違いは？

どちらも条件式では偽として扱われますが、別の値です。見つからない要素は設問の指示に従い `nil` または `-1` を返します。

## Array や Hash の組み込みメソッドを使ってよいですか？

設問ごとのコメントを優先してください。自作 `filter` など、特定の組み込みメソッドを使わずにループやブロックを練習する設問があります。
