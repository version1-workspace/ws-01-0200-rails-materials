# Ruby Practice

## 学ぶこと

- Ruby Syntax：型、条件分岐、繰り返し、メソッド、クラス、モジュール
- List/Queue/Stack：データの保持と取り出し順
- Recursion：再帰と終了条件
- O(n)：入力サイズと時間計算量

## 課題

1. タスクの追加・一覧・削除ができる Ruby のコンソールアプリケーションを作る。
2. リストの走査、FIFO のキュー、LIFO のスタックを実装して利用例を書く。
3. 階乗と入れ子配列の平坦化を再帰で実装する。
4. 線形探索と二重ループによる重複検索を実装し、計算量を比較する。

## 完了条件

- 空のデータや対象が存在しない場合も処理できる。
- キューとスタックの取り出し順を実行例で確認できる。
- 再帰の終了条件と各アルゴリズムの計算量を提出用 README で説明している。
