# モダンな Web アプリ開発

## 注意事項

ブラウザ側の状態と Rails API に保存するデータの役割を整理してください。データベースの認証情報は Rails 側で管理します。

## 課題の進め方

1. PostgreSQL を使う Rails API を用意し、Todo を保存・取得・更新・削除できるようにします。
2. TypeScript・React・Next.js で Todo の画面を作ります。
3. 画面を API につなぎ、追加・一覧表示・完了状態の切り替え・削除を確認します。

[課題完了チェックリスト](#課題完了チェックリスト)で、完了条件を確認してください。

## 学ぶキーワード

- TypeScript によるデータの型定義
- React と Next.js による画面・状態管理
- SPA と Rails API の連携
- PostgreSQL によるデータの永続化

## 課題完了チェックリスト

- [ ] Next.js の画面から Rails API に接続し、Todo の追加・一覧表示・完了状態の切り替え・削除ができる。
- [ ] Todo が PostgreSQL に保存され、画面を再読み込みしても操作結果が反映されている。
- [ ] API の呼び出しが失敗したときに、画面で失敗を確認できる。
