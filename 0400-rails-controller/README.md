# コントローラーと API 開発

## 注意事項

認証が必要な操作と、利用者ごとに許可する操作を実装前に整理してください。入力エラーと認証・認可のエラーで返すステータスを決めておきます。

## 課題の進め方

1. HTTP メソッド、ステータスコード、ヘッダーの理解（チュートリアル）
2. JWT 認証の理解（チュートリアル）
3. JSON API の作成

[課題完了チェックリスト](#課題完了チェックリスト)で、完了条件を確認してください。

## 学ぶキーワード

- HTTPの基本
- MVC アーキテクチャ
- バリデーション
- Form オブジェクト
- ページネーション
- ストロングパラメータ
- コールバック
- 認証・認可

## 課題完了チェックリスト

- [ ] JSON API にリクエストを送り、正常な操作で期待どおりの JSON と HTTP ステータスが返ることを確認した。
- [ ] 必須項目の不足や不正な入力を検証し、理由を JSON で返せることを確認した。
- [ ] 有効な JWT で許可された操作ができ、認証情報がない場合や権限のない操作が拒否されることを確認した。
- [ ] 一覧のページ指定で、該当ページのデータを取得できることを確認した。
