# Ruby on Rails Controller/View

## 学ぶこと

- ルーティング、HTTP メソッド、ステータスコード
- Controller と View の責務、ストロングパラメータ
- フォーム、入力エラー、フラッシュメッセージ、リダイレクト
- 検索、絞り込み、ページネーション
- 認証・認可

## 課題

1. Todo アプリケーションにログインを追加し、自分の Todo だけを表示・更新・削除できるようにする。
2. タイトル検索、完了状態の絞り込み、ページネーションを実装する。
3. 保存失敗時は入力内容を保持してエラーを表示し、成功時はフラッシュメッセージを表示する。
4. 未ログイン、他人の Todo、存在しない Todo へのアクセスを処理する。

## 完了条件

- 正常系と入力エラーをブラウザで確認できる。
- URL やパラメータを変更しても他人の Todo を操作できない。
- アクセス制御とエラー時の挙動を提出用 README に記載している。
