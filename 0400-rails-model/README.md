# Ruby on Rails Model

## 学ぶこと

- PostgreSQL と SQL：CRUD、JOIN、集計、主キー・外部キー
- Active Record と ORM、rails console
- マイグレーション、シード、インデックス、データベース制約
- バリデーション、アソシエーション、コールバック、トランザクション
- 安全なクエリと SQL インジェクション対策

## 課題

1. Todo アプリケーションを PostgreSQL に接続する。
2. ユーザーが複数の Todo を持ち、Todo がカテゴリに属するモデルを作る。
3. マイグレーションとシードを用意し、関連と必須項目の制約を設定する。
4. ユーザー別の未完了 Todo とカテゴリ別の件数を SQL と Active Record の両方で取得する。
5. 複数レコードの更新をトランザクションでまとめ、失敗時のロールバックを確認する。

## 完了条件

- データベースを新規作成してシードを投入できる。
- 不正なデータを拒否し、関連を使って取得できる。
- SQL と Active Record の対応とロールバックの確認方法を提出用 README に記載している。
