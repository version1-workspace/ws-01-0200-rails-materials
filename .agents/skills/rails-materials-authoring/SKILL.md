# Rails 学習課題の作成・編集

教材の進め方は `ws-01-0200-rails-materials` に記載します。対応するサンプル実装は `ws-01-0200-rails-materials-impl` に置きます。

## ディレクトリの命名

リポジトリのルートに `<4桁の番号>-<課題名>` 形式で作成します。番号は先頭をゼロ埋めし、取り組む順に重複なく割り当てます。課題名は内容が分かる英小文字の単語をハイフンでつなぎます。命名例は `0100-rails-entry` です。

## ファイルの配置

- `<課題ディレクトリ>/README.md` を課題の入口とし、取り組むために必要な情報をまとめます。
- 補足ドキュメントは `<課題ディレクトリ>/docs/` に置き、課題の `README.md` から相対リンクで参照します。

## 課題 README の内容

課題名を最上位の見出しにし、次の4項目を記載します。

- **課題の進め方** — 何を作るか、どの順番で取り組むかを記載し、末尾から `[課題完了チェックリスト](#課題完了チェックリスト)` で同じ README 内のチェックリストにリンクします。提出物がある場合はここに記載します。
- **学ぶキーワード** — 課題を通じて学ぶ技術や概念を箇条書きにします。
- **注意事項** — 取り組む前に確認する前提条件や、実装・提出時に守る制約を記載します。
- **課題完了チェックリスト** — `## 課題完了チェックリスト` 見出しの下に、必須要件、動作確認、提出物など、完了に必要な条件を確認可能な粒度で `- [ ]` の項目にします。対応する要件や手順が別の箇所にある場合は、その見出しや補足資料へリンクします。

## 課題一覧の更新

課題を追加した場合は、ルート README の課題一覧に番号順で追加し、課題 README に相対リンクを張ります。
