# Ruby on Rails ApplicationJob

## 学ぶこと

- ApplicationJob と Active Job による非同期実行
- キュー、ワーカー、再試行、重複実行への対応
- Action Mailer によるメール送信
- CSV アップロード、形式検証、取り込み結果の管理

## 課題

1. タイトル・説明・完了状態を持つ CSV の仕様とサンプルを用意する。
2. アップロードした CSV をジョブで読み込み、ログイン中のユーザーの Todo として登録する。
3. 不正なヘッダーや行を検出し、成功件数・失敗件数・行ごとのエラーを記録する。
4. 状態と結果を画面に表示し、完了時にメールで通知する。
5. 再試行しても同じ取り込みで Todo が重複登録されないようにする。

## 完了条件

- Web プロセスとは別のワーカーで取り込みを実行できる。
- 正常・不正・空の CSV と再試行時の挙動を確認できる。
- 開発環境で通知メールの宛先と本文を確認できる。
- ワーカーの起動方法、CSV 仕様、失敗時の扱いを提出用 README に記載している。
