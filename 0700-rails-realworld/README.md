# Ruby on Rails RealWorld

## 学ぶこと

- API mode：JSON API、認証・認可、エラー形式
- SPA：画面遷移、API 通信、状態管理
- RSpec：Model・Request・Job のテスト
- Docker：アプリケーションとデータベースのコンテナ化
- Terraform：インフラのコード化
- Agentic Coding
  - SKILL：作業手順や規約の再利用
  - MCP：外部ツールとの接続
  - AgentReview：エージェントによるレビューと指摘への対応

## 課題

1. API のエンドポイント、入出力、認証方式、エラー形式を定義する。
2. Rails の API mode で、ユーザーごとの Todo の CRUD を実装する。
3. TypeScript と React などで SPA を作り、ログインと CRUD、通信中・失敗時の表示を実装する。
4. RSpec でモデルの制約、API の正常系・認証・認可・入力エラー、ジョブを検証する。
5. Docker Compose で API・SPA・PostgreSQL を起動できるようにする。
6. Terraform でデプロイ先を定義し、構築・デプロイ・削除の手順をまとめる。適用前に利用料金と変更内容を確認する。
7. プロジェクト用の SKILL を作り、MCP で必要なツールを接続して開発に利用する。
8. AgentReview を実施し、指摘の採否と修正・検証結果を記録する。

## 完了条件

- 新しい環境で README の手順から起動でき、SPA から API を利用できる。
- 他人のデータへのアクセスが拒否され、RSpec が成功する。
- Terraform の構成と構築・削除手順があり、秘密情報を含めていない。
- SKILL・MCP の利用内容と AgentReview の対応記録が残っている。
