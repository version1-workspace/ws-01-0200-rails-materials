# Todo アプリの実装手順

[Rails 入門の課題](README.md)で作るシングルページ Todo アプリを、動作確認できる小さな作業に分けます。各段階でブラウザから動作を確認して進めてください。

ここでいうシングルページは、入力フォームと Todo 一覧を1つの画面にまとめることです。JavaScript の SPA フレームワークは必要ありません。Rails と ERB で実装し、操作後に一覧画面へ戻る構成で取り組めます。

## 1. 作るものを決める

- [ ] Todo は「タイトル」と「完了・未完了の状態」を持つ。
- [ ] 同じ画面に追加フォームと一覧を置く。
- [ ] 追加・一覧表示・完了状態の切り替え・削除ができるようにする。

今回はログイン、ユーザーごとの管理、外部 API との連携は対象にしません。タイトルの編集や絞り込みは、基本機能ができた後の追加課題にできます。

## 2. Rails プロジェクトを作成する

- [ ] Ruby、Rails、Bundler を用意し、使用するバージョンを記録する。
- [ ] Rails プロジェクトを作成し、データベースを準備する。最初は SQLite を利用できる。
- [ ] 開発サーバーを起動し、ブラウザでアクセスする。
- [ ] `app/models`、`app/controllers`、`app/views`、`config/routes.rb`、`db/migrate` の役割を確認する。

**確認:** エラーなく起動でき、使った起動コマンドを説明できる。

## 3. Todo を保存できるようにする

- [ ] タイトルと完了状態を保存する Model とマイグレーションを作る。
- [ ] 新規 Todo の完了状態は未完了にする。
- [ ] タイトルの空入力を禁止する。必要に応じて文字数上限も決める。
- [ ] マイグレーションを実行し、rails console で作成・取得を試す。

**確認:** 保存した Todo を取得でき、空のタイトルは保存されない。

## 4. 一覧画面を作る

- [ ] 一覧画面の URL と Controller のアクションをルーティングで結び付ける。
- [ ] Controller から Model を使って Todo を取得する。
- [ ] ERB でタイトルと完了状態を表示する。
- [ ] Todo が0件のときの案内を表示する。

**確認:** 保存した Todo がブラウザに表示され、再読み込みしても残る。

## 5. Todo を追加する

- [ ] 一覧画面にタイトル入力欄と追加ボタンを置く。
- [ ] フォームの送信先と作成用アクションを用意する。
- [ ] Controller で受け取るパラメーターをタイトルに限定する。
- [ ] 保存成功時は一覧画面に戻し、追加した Todo を表示する。
- [ ] 保存失敗時は同じ画面に入力エラーを表示し、既存の一覧も表示する。

**確認:** 正常な入力で1件追加される。空入力では増えず、理由が画面に表示される。

## 6. 完了状態を切り替える

- [ ] 各 Todo に完了・未完了を切り替えるボタンを置く。
- [ ] 対象の Todo を特定して状態を更新する。
- [ ] 状態に応じて表示を変え、操作後は一覧画面に戻す。

**確認:** 未完了から完了、完了から未完了の両方向に切り替えられ、再読み込み後も状態が残る。

## 7. Todo を削除する

- [ ] 各 Todo に削除ボタンを置く。
- [ ] 対象の Todo だけを削除し、一覧画面に戻す。
- [ ] 最後の1件を削除した場合も画面が表示できることを確認する。

**確認:** 選んだ Todo だけが消え、再読み込みしても復活しない。

## 8. 動作と MVC の役割を確認する

- [ ] 追加・一覧・状態切り替え・削除・入力エラーを一通り確認する。
- [ ] タイトルに HTML に見える文字列を入れても、HTML として実行されず文字として表示されることを確認する。
- [ ] 更新・削除は GET で行わず、Rails のフォームと適切な HTTP メソッドを使う。
- [ ] Model の入力検証と、各操作の成功・失敗をテストで確認する。
- [ ] 「URL → Routes → Controller → Model → View」の流れを、自分のコードで説明する。

**責務の目安:** Model はデータと検証、Controller はリクエストと処理の振り分け、View は画面表示を担当します。

## 9. 起動方法をまとめる

- [ ] 実装側の README に、使用バージョン、依存ライブラリのインストール、DB 準備、起動、テストの手順を書く。
- [ ] 実装した機能と MVC に対応するファイルを記載する。
- [ ] README を見ながら起動とテストを実行できることを確認する。

上記のチェックが揃い、1画面で基本操作ができれば、この手順の完了です。
