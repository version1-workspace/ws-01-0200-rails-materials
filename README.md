# Rails 学習課題

Ruby・Rails の基礎から、API 開発、非同期処理、クラウドへのデプロイ、モダンな Web アプリケーション開発までを段階的に学ぶ教材です。

## 課題一覧

番号順に取り組んでください。各段階のリンク先に、やること・学ぶこと・参考資料をまとめています。

| 段階 | 課題 | 主な取り組み |
| --- | --- | --- |
| 0100 | [Rails 入門](0100-rails-entry/README.md) | シングルページの Todo アプリケーションを作成し、Rails の基本と MVC を学ぶ |
| 0200 | [Ruby 演習](0200-ruby-practice/README.md) | 文法・型・クラス・モジュール・アルゴリズムを学び、コンソールアプリケーションを作成する |
| 0300 | [Active Record とデータベース](0300-rails-active-record/README.md) | リレーショナルデータベースと rails console を学び、JSON API を作成する |
| 0400 | [コントローラーと API 開発](0400-rails-controller/README.md) | HTTP・JWT 認証を学び、認証・認可や入力検証を扱う JSON API を作成する |
| 0500 | [非同期処理と業務アプリ](0500-rails-application-job/README.md) | 非同期実行・メール送信・CSV の入出力を学び、業務アプリを作成する |
| 0600 | [クラウドとデプロイ](0600-rails-cloud/README.md) | Docker・AWS・Terraform を学び、Rails アプリケーションをデプロイする |
| 0700 | [モダンな Web アプリ開発](0700-rails-moden-app/README.md) | TypeScript・React・Next.js・Rails・PostgreSQL を使った Todo アプリケーションを作成する |
