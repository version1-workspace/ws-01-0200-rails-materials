# HTML/CSS + Ruby

## 学ぶこと

- HTML のページ構造・フォーム
- CSS のレイアウト・レスポンシブ対応
- Ruby による HTML の生成
- HTTP の GET・POST とリクエスト・レスポンス

## 課題

1. 自己紹介ページを HTML/CSS で作り、PC とスマートフォンで読めるようにする。
2. Ruby でページを配信し、名前とメッセージを送信するフォームを作る。
3. 未入力ならエラーを、入力が揃っていれば確認結果を表示する。

## 完了条件

- ブラウザでページとフォームを利用できる。
- 起動方法と GET・POST の違いを提出用 README に記載している。
